## 1. 问题（Problem）与实例（Instance）

- **算法问题（algorithmic problem）**：一族同类问题的总称，例如"排序问题"、"迷宫问题"、"图着色问题"。
- **实例（instance）**：问题的一个具体输入，例如"把 [3,1,2] 排序"、某一个 10×10 迷宫。
- 一个问题可以有无穷多个实例。**算法必须对所有合法实例都正确**。

| 问题 | 一个实例是什么 |
|---|---|
| 排序 | 一个待排序的序列 |
| 图着色 | 一张图 |
| 解方程组 | 一组线性方程 |

## 2. 什么是算法（Algorithm）

算法是**有限的指令序列**，满足：
1. **无歧义**：每一步都精确定义；
2. **通用**：对所有合法输入都能工作；
3. **有穷**：在有限（合理）时间内结束。

> 第 2 周辅导课题 2：三角形面积公式 S = ½ab·sinθ 算不算算法？
> 不算——它没有说 θ 怎么求出来。海伦公式 √(p(p−a)(p−b)(p−c)) 算，因为每一步都能机械地执行。

## 3. 欧几里得算法（Euclid's Algorithm）求最大公约数

核心事实：gcd(m, n) = gcd(n, m mod n)，且 gcd(m, 0) = m。

```
function Euclid(m, n)
    while n ≠ 0 do
        r ← m mod n
        m ← n
        n ← r
    return m
```

### 手算演示（与讲义相同）

gcd(24, 60)：

| r | m | n |
|---|---|---|
| — | 24 | 60 |
| 24 mod 60 = 24 | 60 | 24 |
| 60 mod 24 = 12 | 24 | 12 |
| 24 mod 12 = 0 | 12 | 0 |

返回 **12**。（注意第一轮 m < n 时，算法会自动把两者交换。）

gcd(171, 7)：r = 3 → (7, 3)；r = 1 → (3, 1)；r = 0 → (1, 0)，返回 **1**。

### 对比：暴力 gcd
从 t = min(m, n) 开始往下试，第一个同时整除 m 和 n 的 t 就是答案。最坏要试 min(m,n) 次。
讲义里同样计算 gcd(2147483647, 2147483646)：暴力要 4 分钟，欧几里得只要 0.000004 秒。

### 复杂度（第 4 讲末尾补充）
每**两轮**迭代 m 至少减半（因为 1 < n < m ⇒ m mod n < m/2），所以迭代次数是 **O(log(m + n))**，
即与输入的**位数**成线性关系。这就是"减治"（decrease-and-conquer）思想的第一个例子。

## 4. 解决问题的步骤（第 1 讲）
1. 理解问题 → 2. 决定计算方式（串行/并行、精确/近似）→ 3. 选设计策略 →

## 5. 变治思想的小例子：残缺棋盘（Mutilated Checkerboard，第 2 讲）

8×8 棋盘去掉对角两个角，能否用 31 块 1×2 骨牌铺满？
暴力法要试所有摆法。聪明的做法是**换个角度看（抽象）**：
- 对角两个角颜色相同（比如都是白色），去掉后剩 30 白、32 黑；
- 每块骨牌必定盖住 1 白 1 黑，31 块骨牌应盖 31 白 31 黑；
- 矛盾 ⇒ **不可能**。
这就是后面"变治法"（transform and conquer）的思想：换一个表示，问题立刻变简单。

## 6. 基本数据结构

### 6.1 数组（Array）
- 内存中连续的格子，A[0..n−1]（也有教材用 A[1..n]）。
- **按下标访问 O(1)**（直接算地址）。
- 缺点：插入/删除要移动后面的元素，O(n)；大小固定。

### 6.2 链表（Linked List）
- 每个结点有 `val`（值）和 `next`（指向下一个结点的指针），最后一个指向 `null`。
- **插入/删除 O(1)**（只改几个指针，前提是已经找到位置）。
- **找第 i 个元素 O(i)**（必须从头走）。
- 常用"哑结点"（dummy head）简化插入删除的代码。

### 6.3 遍历：数组 vs 链表（注意两者的相似性）

```
function Find(A, x, n)            function Find(head, x)
    j ← 0                             p ← head
    while j < n do                    while p ≠ null do
        if A[j] = x then                  if p.val = x then
            return j                          return p
        j ← j + 1                         p ← p.next
    return −1                         return null
```

递归版本（把问题化成"更小的同类问题"）：

```
function Find(A, x, lo, hi)       function Find(p, x)
    if lo > hi then                   if p = null then
        return −1                         return null
    else if A[lo] = x then            else if p.val = x then
        return lo                         return p
    else                              else
        return Find(A, x, lo+1, hi)       return Find(p.next, x)
初始调用 Find(A, x, 0, n−1)        初始调用 Find(head, x)
```

### 6.4 抽象数据类型（ADT）
一组数据 + 一组操作（接口/契约）。**使用者只通过操作访问数据，不关心内部实现**。
栈、队列、优先队列、字典都是 ADT，可以用数组或链表来实现。

### 6.5 栈（Stack）—— 后进先出 LIFO
操作：`CreateStack`、`Push(x)`、`Pop()`、`Top()`、`IsEmpty()`。
- 数组实现：用变量 `top` 记录栈顶位置，Push 时 `top ← top + 1; A[top] ← x`。
- 链表实现：在表头插入/删除。

```
function Push(st, x)
    elt ← new node
    elt.val ← x
    elt.next ← st
    st ← elt
    return st
```

用途：**DFS（深度优先搜索）**、递归调用栈、括号匹配、撤销操作。

### 6.6 队列（Queue）—— 先进先出 FIFO
操作：`CreateQueue`、`Enqueue(x)`（入队尾）、`Dequeue()`（出队头）、`Head()`、`IsEmpty()`。
用途：**BFS（广度优先搜索）**、层序遍历、调度。

### 6.7 后面会遇到的其他结构
优先队列（第 13 讲，堆）、各种树（第 12、14、15 讲）、图（第 7 讲）、字典/哈希表（第 17 讲）。

## 考点与易错

- **算法的三个要求**：无歧义、对所有输入正确、有限时间结束。
- 欧几里得算法若 m < n，第一轮会自动交换，不用特别处理。
- 数组随机访问 O(1)，链表 O(n)；链表插入删除 O(1)（找到位置后）。
- 栈 = LIFO → DFS；队列 = FIFO → BFS。这个对应关系一定要记住。

1. 表示 Σ_{i=0}^{n−1} 2ⁱ·xᵢ。从左往右处理，"累加器翻倍再加当前位"：
   ```
   function BinToDec(x_{n−1} … x_0)
       a ← 0
       for i ← 0 to n − 1 do
           a ← 2a + x_{n−i−1}
       return a
   ```
2. 从右往左生成位：不断取 d mod 2，再把 d 减半。
   ```
   function DecToBin(d)
       n ← 0
       while d ≠ 0 do
           x_n ← d mod 2
           d ← ⌊d/2⌋
           n ← n + 1
       return x_{n−1} … x_0
   ```
