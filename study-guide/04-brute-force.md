# 第 4 章（第 5 讲）暴力法与穷举搜索（Brute Force & Exhaustive Search）

> **本章位置**：第一个"算法设计策略"。暴力法 = 直接照着问题定义去做。
> 它通常很慢，但简单、通用，是设计题里**最先想到的基准方案**，也是后面所有优化的出发点。
> **考试比重**：选择排序及排序三性质（稳定/原地/输入不敏感）是选择题常客；
> 字符串匹配比较次数是计算题常客；穷举搜索的复杂度（2ⁿ、n!）要会判断。
> ⚠️ 凸包（convex hull）**不考**。

---

## 1. 选择排序（Selection Sort）

**思想**：第 i 轮从 A[i..n−1] 里找出最小值，与 A[i] 交换。

```
function SelectionSort(A[0..n−1])
    for i ← 0 to n − 2 do
        min ← i
        for j ← i + 1 to n − 1 do
            if A[j] < A[min] then
                min ← j
        swap(A[i], A[min])
```

### 手算演示（第 4 周题 16：S O R T X A M P L E）
每行是第 i 轮交换后的结果，`|` 左边已排好：

| i | 本轮最小 | 结果 |
|---|---|---|
| 0 | A | A \| O R T X S M P L E |
| 1 | E | A E \| R T X S M P L O |
| 2 | L | A E L \| T X S M P R O |
| 3 | M | A E L M \| X S T P R O |
| 4 | O | A E L M O \| S T P R X |
| 5 | P | A E L M O P \| T S R X |
| 6 | R | A E L M O P R \| S T X |
| 7 | S | A E L M O P R S \| T X |
| 8 | T | A E L M O P R S T X |

### 复杂度
比较次数 = n(n−1)/2 ∈ **Θ(n²)**，**不管输入是什么都一样**。
但**交换只有 n − 1 次** ⇒ 适合"记录很大、数量很少"的情况（移动记录代价高）。

## 2. 排序算法的三个性质（全课反复考！）

| 性质 | 含义 |
|---|---|
| **原地（in-place）** | 除了几个变量外不需要额外内存 |
| **输入不敏感（input-insensitive）** | 运行时间基本只取决于 n，与输入的具体排列无关 |
| **稳定（stable）** | 关键字相同的元素，排序后保持原来的相对顺序 |

### 选择排序：原地 ✔，输入不敏感 ✔，**不稳定 ✘**
反例（讲义）：按 key 排序 [4ᵃᵇ, 3ᵇᶜ, 4ᵈᵉ, 3ᶠᵍ]
- i=0：最小是 3ᵇᶜ（下标 1），与 4ᵃᵇ 交换 → [3ᵇᶜ, 4ᵃᵇ, 4ᵈᵉ, 3ᶠᵍ]
- i=1：最小是 3ᶠᵍ（下标 3），与 4ᵃᵇ 交换 → [3ᵇᶜ, 3ᶠᵍ, 4ᵈᵉ, 4ᵃᵇ]
- 两个 4 的相对顺序变了（ab 本来在 de 前面）⇒ **不稳定**。

> 判断稳定性的诀窍：看算法有没有**"长距离交换"**——把一个元素跳过一堆元素扔到远处，通常就不稳定。

## 3. 暴力字符串匹配（Brute-Force String Matching）

文本 t（长度 n），模式 p（长度 m）。把 p 依次对齐到 t 的每个位置 i = 0..n−m，从左往右逐个比。

```
function BruteForceMatch(t[0..n−1], p[0..m−1])
    for i ← 0 to n − m do
        j ← 0
        while j < m and p[j] = t[i + j] do
            j ← j + 1
        if j = m then
            return i
    return −1
```

### 复杂度
- 基本操作：字符比较 `p[j] = t[i+j]`。
- 最坏：n − m + 1 个位置，每个位置比 m 次 ⇒ **O(mn)**。
  最坏例子：t = 000…0（n 个 0），p = 00…01（m−1 个 0 再一个 1），共 (n−m+1)·m 次比较。
  该函数在 m ≈ n/2 时最大。
- 对随机英文文本，通常第一个字符就失配，**平均接近线性 Θ(n)**。

### 计数练习（第 4 周题 18、19）
- p = `needle`，t = `there_need_not_be_any`：共 **21** 次字符比较（找不到）。
  （共 21−6+1 = 16 个对齐位置。14 个位置第一个字符就失配，各 1 次；
  "need_" 处比到第 5 个字符才失配，5 次；"no" 处 2 次。14 + 5 + 2 = 21。）
- 文本是 100 万个 0：
  - p = `010001`：每个位置第 1 个字符匹配、第 2 个失配 ⇒ 每位置 2 次，共 2 × 999995 次；
  - p = `000101`：每位置 4 次（前三个 0 匹配，第 4 个失配），共 4 × 999995；
  - p = `011101`：每位置 2 次，共 2 × 999995。
  （位置数 = 10⁶ − 6 + 1 = 999995。）

## 4. 最近点对（Closest Pair）暴力法

n 个平面点，找距离最小的一对。暴力：检查所有 i < j 的点对。

```
function ClosestPairBF(P[0..n−1])
    dmin ← ∞
    for i ← 0 to n − 2 do
        for j ← i + 1 to n − 1 do
            d ← (xᵢ − xⱼ)² + (yᵢ − yⱼ)²      ▷ 比较平方距离，省去开方
            if d < dmin then
                dmin ← d
    return dmin
```
复杂度 **Θ(n²)**。去掉开方（因为 √ 是单调的，a < b ⇔ √a < √b）只是常数级加速，不改变 Θ(n²)。
第 12 讲会用分治做到 **Θ(n log n)**。

## 5. 穷举搜索（Exhaustive Search）

适用于组合问题（找最优排列、子集……）。方法："**生成并测试**"：
1. 系统地生成所有候选解；
2. 逐个评估，记录目前最好的；
3. 全部检查完后返回最好的。

| 问题 | 候选解 | 数量 | 复杂度 |
|---|---|---|---|
| 旅行商 TSP（访问每个城市一次回到起点，最短环路） | 城市的排列 | (n−1)!/2 | Θ(n!) |
| 0/1 背包（容量 W，选总重 ≤ W 的物品使价值最大） | 物品子集 | 2ⁿ | Θ(n·2ⁿ) |
| 分配问题（n 人 n 工作，最小总成本） | 排列 | n! | Θ(n·n!) |
| 子集和（是否有子集和为 t） | 子集 | 2ⁿ | Θ(n·2ⁿ) |

### 分配问题手算（第 4 周题 21）
成本矩阵 C[人, 工作]：

|  | 工作1 | 工作2 | 工作3 | 工作4 |
|---|---|---|---|---|
| 人1 | 9 | 2 | 7 | 8 |
| 人2 | 6 | 4 | 3 | 7 |
| 人3 | 5 | 8 | 1 | 8 |
| 人4 | 7 | 6 | 9 | 4 |

枚举所有 4! = 24 个排列（排列 ⟨j₁,j₂,j₃,j₄⟩ 表示人 i 做工作 jᵢ），例如
⟨1,2,3,4⟩ = 9+4+1+4 = 18，⟨2,1,3,4⟩ = 2+6+1+4 = **13**（最小）。

> 注意：最优解**不一定**包含矩阵中最小的元素（题 22）：C = [[1,2],[2,4]]，
> 选 1 则另一个必须是 4，总 5；不选 1 是 2+2 = 4 更好。

### 哈密顿回路 vs 欧拉回路（"看起来像，难度天差地别"）
- **哈密顿回路**：经过**每个结点**恰好一次回到起点。→ **难**（NP 完全，只知道穷举）。
- **欧拉回路**：经过**每条边**恰好一次。→ **容易**：连通且每个结点度数都是偶数即可，线性时间判定。

对 TSP、背包这类问题，目前不知道比穷举本质上更好的精确算法；
可以用**近似算法**（快、接近最优）。背包后面会用**动态规划**做到 Θ(nW)。

---

## 考点与易错

1. 选择排序：Θ(n²) 比较、Θ(n) 交换；原地、输入不敏感、**不稳定**。
2. 暴力字符串匹配最坏 O(mn)，平均（自然语言文本）接近线性。
3. 数比较次数时，**失配的那一次也算一次比较**。
4. 穷举搜索：子集 → 2ⁿ，排列 → n!。
5. 欧拉回路容易、哈密顿回路困难。

<details>
<summary>答案</summary>

1. 比较仍是 n(n−1)/2；swap 仍调用 n − 1 次（每次 i = min，自己和自己交换）。选择排序是输入不敏感的。
2. 枚举 S 的所有 2ⁿ 个子集，对每个子集求和（O(n)），等于 t 就返回。
   ```
   function SubsetSum(S[1..n], t)
       for each subset S' of S do      ▷ 可用 0..2ⁿ−1 的二进制位表示子集
           if sum(S') = t then return S'
       return "none"
   ```
   复杂度 Θ(n·2ⁿ)（若增量求和可做到 Θ(2ⁿ)）。
3. 设总和为 s。若 s 是奇数，直接回答"不能"；否则问"是否有子集和为 s/2"——调用子集和算法即可。
   （这就是第 22 讲"问题归约"的思想。）
4. 团：枚举所有 k 个结点的子集（C(|V|,k) 个），检查每对之间是否都有边。
   三角形：三重循环枚举结点三元组 (u,v,w)（|V|³ 个），每次在边表中检查三条边（O(|E|)）⇒ O(|V|³|E|)。
5. 位置 i = 0..15（n−m+1 = 18−3+1 = 16 个）。i=0: N=N, O=O, B≠T → 3 次；i=7: N,O,T 全匹配 → 3 次，返回 7。
   i=1..6 各 1 次（第一个字符失配）共 6 次。总计 3 + 6 + 3 = **12** 次。
