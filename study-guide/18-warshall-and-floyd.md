# 第 18 章（第 19 讲）图上的动态规划：Warshall 算法与 Floyd 算法

> **本章位置**：把上一讲的 DP 用到图上。两个算法结构几乎一模一样：三重循环，k 在最外层。
> - **Warshall**：有向图的**传递闭包**（谁能到达谁）；
> - **Floyd**：**所有点对之间的最短路径**。
> **考试比重**：手算矩阵的每一轮（R⁽ᵏ⁾、D⁽ᵏ⁾）是典型题；也会问复杂度和适用条件（负权）。

---

## 1. 传递闭包（Transitive Closure）

**定义**：有向图 G 的传递闭包中有边 (a, z) 当且仅当 G 中存在一条从 a 到 z 的（非空）路径。
用途：可达性分析——某个"状态"能否从"初始状态"到达（例如集装箱能否通过一系列操作重新排列成某种布局）。

## 2. Warshall 算法

### 2.1 思路（DP 的子问题）
结点编号 1..n。问："**只用编号 ≤ k 的结点作为中转站**（stepping stones），能否从 i 走到 j？"
这样的路径要么**不经过** k，要么**经过** k：
- 不经过 k：只用 ≤ k−1 的结点就能从 i 到 j；
- 经过 k：只用 ≤ k−1 的结点从 i 到 k，再只用 ≤ k−1 的结点从 k 到 j。

```
R⁽⁰⁾[i, j] = A[i, j]                                   （邻接矩阵）
R⁽ᵏ⁾[i, j] = R⁽ᵏ⁻¹⁾[i, j]  or  ( R⁽ᵏ⁻¹⁾[i, k]  and  R⁽ᵏ⁻¹⁾[k, j] )
```
R⁽ⁿ⁾ 就是传递闭包。

```
function Warshall(A[1..n, 1..n])
    R⁽⁰⁾ ← A
    for k ← 1 to n do
        for i ← 1 to n do
            for j ← 1 to n do
                R⁽ᵏ⁾[i, j] ← R⁽ᵏ⁻¹⁾[i, j] or (R⁽ᵏ⁻¹⁾[i, k] and R⁽ᵏ⁻¹⁾[k, j])
    return R⁽ⁿ⁾
```

### 2.2 改进版（直接在 A 上改）
若 A[i, k] = 0，这一行什么都不变；若 A[i, k] = 1，则对所有 A[k, j] = 1 的 j 置 A[i, j] = 1。
测试 A[i, k] 与 j 无关，可以提到最内层循环外面：
```
function Warshall(A[1..n, 1..n])
    for k ← 1 to n do
        for i ← 1 to n do
            if A[i, k] then
                for j ← 1 to n do
                    if A[k, j] then
                        A[i, j] ← 1
    return A
```
**手算口诀**：第 k 轮，看**第 k 列**中哪些行是 1；把**第 k 行** "或"（OR）到这些行上。
（若每行用位串表示，最内层循环就是一次按位或。）

### 2.3 手算演示（第 11 周题 78）
边：a→c, a→d, b→c, c→a

| R⁽⁰⁾ | a | b | c | d |
|---|---|---|---|---|
| a | 0 | 0 | 1 | 1 |
| b | 0 | 0 | 1 | 0 |
| c | 1 | 0 | 0 | 0 |
| d | 0 | 0 | 0 | 0 |

- **k = a**：第 a 列中为 1 的行：c。把第 a 行 0011 或到第 c 行：c = 1000 | 0011 = **1011**。
- **k = b**：第 b 列全为 0，不变。
- **k = c**：第 c 列中为 1 的行：a、b、c。第 c 行是 1011：a = 0011 | 1011 = **1011**；b = 0010 | 1011 = **1011**；c 不变。
- **k = d**：第 d 列中为 1 的行：a、b、c，但第 d 行全 0，不变。

| R⁽⁴⁾ | a | b | c | d |
|---|---|---|---|---|
| a | 1 | 0 | 1 | 1 |
| b | 1 | 0 | 1 | 1 |
| c | 1 | 0 | 1 | 1 |
| d | 0 | 0 | 0 | 0 |

（a 到 a 为 1，因为有环 a→c→a。）

### 2.4 复杂度
- **Θ(n³)**，最好、平均、最坏都一样。
- 适合**稠密图**（内循环很紧凑）。
- **稀疏图**更好的办法：从每个结点各做一次 DFS/BFS，记录能到达哪些结点：n 次 × Θ(n + |E|) = Θ(n² + n|E|)。

## 3. Floyd 算法：所有点对最短路径（All-Pairs Shortest Paths）

- 输入：带权图（有向或无向）的**权矩阵** W；没有边时 W[i, j] = ∞，W[i, i] = 0。
- 要求权值为正（有时负权也行，但**不能有负权环**）。
- 输出：**距离矩阵** D，D[i, j] = i 到 j 的最短路径长度。

### 3.1 递推关系（与 Warshall 同样的分解）
"只用编号 ≤ k 的结点作中转，i 到 j 的最短路径长度是多少？" 要么不经过 k，要么经过 k：
```
D⁽⁰⁾[i, j] = W[i, j]
D⁽ᵏ⁾[i, j] = min( D⁽ᵏ⁻¹⁾[i, j],  D⁽ᵏ⁻¹⁾[i, k] + D⁽ᵏ⁻¹⁾[k, j] )
```

```
function Floyd(W[1..n, 1..n])
    D ← W
    for k ← 1 to n do
        for i ← 1 to n do
            for j ← 1 to n do
                D[i, j] ← min(D[i, j], D[i, k] + D[k, j])
    return D
```
**Θ(n³)**（只需要最后一个矩阵，可以原地覆盖）。若要输出路径本身，可另存一个"经过哪个 k"的矩阵。

**手算口诀**：第 k 轮，对每个 (i, j)，看"**走第 k 行第 k 列中转**"是否更短：D[i, k] + D[k, j] < D[i, j]？
第 k 行和第 k 列本身在第 k 轮不会变。

### 3.2 手算演示（讲义）
有向边：a→b 2，a→c 5，b→c 1，c→d 2，d→e 3，e→c 2

D⁽⁰⁾ = W：
|   | a | b | c | d | e |
|---|---|---|---|---|---|
| a | 0 | 2 | 5 | ∞ | ∞ |
| b | ∞ | 0 | 1 | ∞ | ∞ |
| c | ∞ | ∞ | 0 | 2 | ∞ |
| d | ∞ | ∞ | ∞ | 0 | 3 |
| e | ∞ | ∞ | 2 | ∞ | 0 |

- **k = a**：没有边进入 a（第 a 列除对角线外都是 ∞），D⁽¹⁾ = D⁽⁰⁾。
- **k = b**：a→b→c = 2 + 1 = 3 < 5 ⇒ D[a, c] = **3**。
- **k = c**：经过 c：a→d = 3 + 2 = **5**；b→d = 1 + 2 = **3**；e→d = 2 + 2 = **4**。
- **k = d**：经过 d：a→e = 5 + 3 = **8**；b→e = 3 + 3 = **6**；c→e = 2 + 3 = **5**。
- **k = e**：经过 e：d→c = 3 + 2 = **5**。

D⁽⁵⁾（最终）：
|   | a | b | c | d | e |
|---|---|---|---|---|---|
| a | 0 | 2 | 3 | 5 | 8 |
| b | ∞ | 0 | 1 | 3 | 6 |
| c | ∞ | ∞ | 0 | 2 | 5 |
| d | ∞ | ∞ | 5 | 0 | 3 |
| e | ∞ | ∞ | 2 | 4 | 0 |

### 3.3 负权与负权环（第 12 周题 79）
Floyd 对负权**有时**可以，但如果图中有**负权环**，"最短路径"没有意义（可以绕环无限变小），结果会出错。
例：a→b 权 3，b→a 权 −4（环 a→b→a 总权 −1）：
D⁽⁰⁾ = [[0, 3], [−4, 0]]，D⁽¹⁾ = [[0, 3], [−4, −1]]，D⁽²⁾ = [[−1, 2], [−5, −2]]——对角线出现负数，全错。
**改进**：一旦对角线上出现负数，就报错停止。

### 3.4 最优子结构
DP 能用的前提是问题有"子结构性质"：
- **最短路径有**：若 x₁ – x₂ – … – xᵢ – … – xₙ 是 x₁ 到 xₙ 的最短路径，则 x₁ – … – xᵢ 也是 x₁ 到 xᵢ 的最短路径。
- **最长（简单）路径没有**：讲义例子中 1–3–4–2–5 是 1 到 5 的最长路径，但 1–3–4–2 不是 1 到 2 的最长路径（1–3–4–5–2 更长）。
  所以不能用同样的 DP 求一般图的最长简单路径（但 DAG 上可以，见第 17 章练习）。

## 考点与易错

1. **k 必须在最外层循环**（先固定中转站，再枚举所有 i、j）。把 k 放里面是错的。
2. Warshall：or/and；Floyd：min/+。两者都是 Θ(n³)。
3. Warshall 手算：看第 k 列的 1，把第 k 行 OR 进去。Floyd 手算：D[i,k] + D[k,j] 与 D[i,j] 比较。
4. Floyd 不允许负权环；对角线出现负数说明有负权环。
5. 稀疏图求传递闭包：从每个点 DFS 更好。
6. 单源最短路径用 Dijkstra（下一章）更快；所有点对用 Floyd。

4. 设计算法：给定有向图，求出所有"能互相到达"的结点对 (u, v)（u 能到 v 且 v 能到 u）。复杂度？

1. 矩阵行用位串（列顺序 a b c d）：R⁽⁰⁾：a 0100, b 0001, c 0000, d 1010。
