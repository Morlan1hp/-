# 第 9 章（第 10 讲）减治法之二：按因子减小（Decrease-and-Conquer by a Factor）

> **本章位置**：减治的升级版，每步把规模缩小一个**比例**，常常得到对数甚至更快的算法。
> 本讲：二分查找（减半）、插值查找（可变因子）、**Lomuto 划分**和 **QuickSelect**（找第 k 小）。
> **考试比重**：QuickSelect 追踪、插值查找的计算、各算法复杂度是常考点。
> Lomuto 划分是下一讲快速排序的前奏。

---

## 1. 二分查找（Binary Search）——减常数因子

前提：**数组有序**。与中间元素 A[m] 比较：相等则找到；A[m] > k 则在左半边找；否则在右半边找。

```
function BinarySearch(A[0..n−1], k)
    lo ← 0
    hi ← n − 1
    while lo ≤ hi do
        m ← ⌊(lo + hi)/2⌋
        if A[m] = k then
            return m
        else if A[m] > k then
            hi ← m − 1
        else
            lo ← m + 1
    return −1
```

### 手算演示
A = [4, 9, 13, 22, 41, 83, 96]（下标 0..6），找 41：

| lo | hi | m | A[m] | 动作 |
|---|---|---|---|---|
| 0 | 6 | 3 | 22 | 22 < 41，lo ← 4 |
| 4 | 6 | 5 | 83 | 83 > 41，hi ← 4 |
| 4 | 4 | 4 | 41 | 找到，返回 4 |

### 复杂度
- **最坏输入：k 不在数组中**。C(n) = C(⌊n/2⌋) + 1，C(1) = 1 ⇒ C(n) = ⌊log₂n⌋ + 1 ∈ **Θ(log n)**。
- 100 万个元素最多 20 次比较。
- **平均情况也是 Θ(log n)**。

## 2. 插值查找（Interpolation Search）——减可变因子

**动机**：查电话簿找 "Zobel"，你会直接翻到最后附近，而不是从中间开始。
若有序数组的值**分布比较均匀**，可以按值的比例估计位置：

```
m ← lo + ⌊ (k − A[lo]) / (A[hi] − A[lo]) · (hi − lo) ⌋
```
（就是在点 (lo, A[lo]) 和 (hi, A[hi]) 之间做线性插值。）其余步骤与二分查找相同。
**每次探测前必须检查 A[lo] ≤ k ≤ A[hi]**，否则直接判定找不到。

### 手算演示 1（讲义）
A = [4, 9, 13, 22, 41, 83, 96]，找 83：
m = 0 + ⌊(83 − 4)/(96 − 4) · 6⌋ = ⌊79/92 · 6⌋ = ⌊5.15⌋ = 5，A[5] = 83，**一次找到**。

### 手算演示 2（第 6 周题 40）
A[0..21] = 20, 20, 21, 23, 25, 26, 26, 27, 29, 29, 29, 30, 32, 33, 34, 36, 38, 40, 41, 43, 43, 45，找 42：
- m = 0 + ⌊(42 − 20)/(45 − 20) · 21⌋ = ⌊22/25 · 21⌋ = ⌊18.48⌋ = **18**，A[18] = 41 < 42 ⇒ lo ← 19。
- 新区间 A[19..21] = 43, 43, 45。先检查端点：A[19] = 43 > 42 ⇒ k 不可能在其中，**立即报告失败**。

### 复杂度
- 均匀分布时平均 **O(log log n)**——非常快。
- 最坏（分布极不均匀）可以退化到 O(n)。
- 适合**大数组 + 均匀分布**的数据。

## 3. 第 k 小元素与中位数

**中位数**：不大于一半元素、也不小于一半元素的值。推广：**找第 k 小元素**（selection problem）。
最直接：先排序 O(n log n)，再取 A[k−1]。但排序是"杀鸡用牛刀"。

### 3.1 划分（Partitioning）
以某个**枢轴（pivot）** p 重排数组，使 p 左边都 ≤ p，右边都 ≥ p。此时 **p 已在最终排好序的位置**。

### 3.2 Lomuto 划分（课上版本，pivot = 第一个元素）

```
function LomutoPartition(A[lo..hi])
    p ← A[lo]
    s ← lo                          ▷ s 指向"小于 p 的区域"的最后一个
    for i ← lo + 1 to hi do
        if A[i] < p then
            s ← s + 1
            swap(A[s], A[i])
    swap(A[lo], A[s])               ▷ 把 pivot 放到中间
    return s
```

不变式：A[lo+1..s] < p，A[s+1..i−1] ≥ p。

**手算（讲义）**：A = [9, 23, 3, 41, 22, 8, 46]，p = 9

| i | A[i] | < 9? | s | 数组 |
|---|---|---|---|---|
| 1 | 23 | 否 | 0 | 9 23 3 41 22 8 46 |
| 2 | 3 | 是 | 1 | 9 **3 23** 41 22 8 46（交换 A[1]、A[2]） |
| 3 | 41 | 否 | 1 | 9 3 23 41 22 8 46 |
| 4 | 22 | 否 | 1 | 9 3 23 41 22 8 46 |
| 5 | 8 | 是 | 2 | 9 3 **8** 41 22 **23** 46（交换 A[2]、A[5]） |
| 6 | 46 | 否 | 2 | 9 3 8 41 22 23 46 |
| 结束 | | | | 交换 A[0]、A[2] → **8 3 9 41 22 23 46**，返回 s = 2 |

### 3.3 QuickSelect（找第 k 小，k 从 1 开始数）

划分后 pivot 在下标 s，它是子数组中第 s − lo + 1 小的：
- 若 s − lo = k − 1：pivot 就是答案；
- 若 s − lo > k − 1：答案在左边，在 A[lo..s−1] 中找第 k 小；
- 否则答案在右边，在 A[s+1..hi] 中找第 **k − (s − lo + 1)** 小。

```
function QuickSelect(A[lo..hi], k)
    s ← LomutoPartition(A[lo..hi])
    if s − lo = k − 1 then
        return A[s]
    else if s − lo > k − 1 then
        return QuickSelect(A[lo..s−1], k)
    else
        return QuickSelect(A[s+1..hi], (k − 1) − (s − lo))
```

**手算 1（讲义）**：[9, 23, 3, 41, 22, 8, 46] 中找第 6 小（答案应为 41）
1. 划分整个数组 → 8 3 9 41 22 23 46，s = 2。s − lo = 2 < 5 ⇒ 去右边，新 k = 5 − 2 = 3，范围 [3..6]。
2. 划分 A[3..6] = 41 22 23 46，p = 41：22 < 41（s=4），23 < 41（s=5），46 否；交换 A[3]、A[5] → 23 22 41 46，s = 5。
   s − lo = 5 − 3 = 2 = k − 1 ⇒ 返回 **41** ✔。

**手算 2（第 7 周题 42）**：求 39, 23, 12, 77, 48, 61, 55 的中位数（n = 7 ⇒ k = 4）
1. p = 39：23、12 都 < 39（无用的原地交换），其余都大；s = 2，交换 → 12 23 39 77 48 61 55。
   s − lo = 2 < 3 ⇒ 右边 A[3..6]，新 k = 3 − 2 = 1。
2. A[3..6] = 77 48 61 55，p = 77，其余都 < 77，s = 6，交换 A[3]、A[6] → 55 48 61 77。
   s − lo = 3 > 0 ⇒ 左边 A[3..5]，k = 1。
3. A[3..5] = 55 48 61，p = 55：48 < 55（s=4），61 否；交换 → 48 55 61，s = 4。
   s − lo = 1 > 0 ⇒ 左边 A[3..3]，k = 1。
4. A[3..3] = 48，s = 3，s − lo = 0 = k − 1 ⇒ 返回 **48**。

### 3.4 QuickSelect 复杂度
- **平均：线性 Θ(n)**（每次大约减半：T(n) = T(n/2) + n ⇒ Θ(n)）。
- **最坏：Θ(n²)**（每次 pivot 都是最大或最小，例如已排序数组找最大）。

> 第 7 周题 43：找最小值时，直接扫描一遍（n − 1 次比较）比 QuickSelect 好——
> QuickSelect 光第一次划分就要 n − 1 次比较，而且可能要很多轮。

---

## 考点与易错

1. 二分查找要求有序；最坏和平均都是 Θ(log n)；最坏输入是"找不到"。
2. 插值查找：公式 m = lo + ⌊(k − A[lo])(hi − lo)/(A[hi] − A[lo])⌋；均匀分布时 O(log log n)；**先检查端点**。
3. Lomuto：pivot 取 A[lo]，`if A[i] < p then s ← s+1; swap`，最后 swap(A[lo], A[s])。
4. QuickSelect 递归到右边时 **k 要减去 (s − lo + 1)**；平均 Θ(n)，最坏 Θ(n²)。
5. log log n ≺ log n（插值查找比二分查找快）。
