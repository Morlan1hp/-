> **本章位置**：第四种设计策略——变治（Transform and Conquer）：先把问题**变换**成更容易的形式，再解决。
> 上一讲的堆其实就是"换表示"的例子。本讲讲预排序和二叉搜索树（BST），下一讲讲平衡树。
> **考试比重**：**预排序是设计题最常用的技巧之一**（"先排序再线性扫描"）；BST 插入、中序遍历常考。

## 1. 变治法的三种形式

| 形式 | 含义 | 例子 |
|---|---|---|
| 实例简化（instance simplification） | 把实例变成更简单/更方便的同类实例 | **预排序**、AVL 树（保持平衡） |
| 表示变换（representation change） | 换一种数据表示 | 堆、2–3 树、霍纳法则、残缺棋盘的染色 |
| 问题归约（problem reduction） | 变成另一个已经会解的问题 | 划分问题 → 子集和；硬币行 → DAG 最长路；第 22 讲 |

## 2. 预排序（Presorting）

很多数组问题，**排序之后会简单很多**。排序用 Θ(n log n)（归并或堆排序），之后通常只需线性扫描，
所以整体 Θ(n log n)，往往比暴力的 Θ(n²) 好。

### 2.1 元素唯一性检查（是否所有元素互不相同）

暴力：比较所有对。
```
function UniqueBF(A[0..n−1])
    for i ← 0 to n − 2 do
        for j ← i + 1 to n − 1 do
            if A[i] = A[j] then return False
    return True
```
最坏 Θ(n²)。

预排序：相同的元素排序后一定**相邻**。
```
function UniquePresort(A[0..n−1])
    Mergesort(A)
    for i ← 0 to n − 2 do
        if A[i] = A[i + 1] then return False
    return True
```
Θ(n log n) + Θ(n) = **Θ(n log n)**。

### 2.2 求众数（mode，出现次数最多的元素）

例：42, 78, 13, 13, 57, 42, 57, 78, 13, 98, 42, 33 中众数是 13 和 42（各 3 次）。

暴力：对每个不同元素，再扫一遍数它的个数 ⇒ Θ(n²)。
预排序：排序后相同元素连成一段（run），找最长的一段：
```
function ModePresort(A[0..n−1])
    Mergesort(A)
    i ← 0
    maxfreq ← 0
    while i < n do
        runlength ← 1
        while i + runlength < n and A[i + runlength] = A[i] do
            runlength ← runlength + 1
        if runlength > maxfreq then
            maxfreq ← runlength
            mode ← A[i]
        i ← i + runlength
    return mode
```
排序之后的部分是线性的 ⇒ 总 **Θ(n log n)**。

### 2.3 查找：要查很多次时，先排序
在无序数组中查找 m 个元素：
- 顺序查找 m 次：m·n
- 先排序再二分：n log n + m log n

讲义估算（最坏情况）：n = 1024，m = 32：顺序查找 32 × 1024 = 32768；排序 + 二分 10240 + 320 = 10560。
**查询次数多时，预排序划算**。

### 2.4 找变位词（anagram）
"ate, tea, eat" 互为变位词（字母相同、顺序不同）。给一个很长的单词表，找出所有变位词组：
1. 对每个单词，把它的字母排序得到**签名**（eat → aet，tea → aet）；
2. 把 (签名, 单词) 按签名排序（如归并排序）；
3. 签名相同的相邻单词就是一组变位词。

两个单词是否互为变位词（第 3 周题 8）：分别排序字母再比较即可。

## 3. 二叉搜索树（Binary Search Tree, BST）

**定义**：每个内部结点存一个元素，且对**每棵子树**都满足 BST 性质：
> 设根为 r，则左子树所有元素 **< r**，右子树所有元素 **> r**。（假设键互不相同。）

### 3.1 查找
```
function BSTSearch(T, k)
    if T = null then return null           ▷ 找不到
    if k = T.root then return T
    if k < T.root then return BSTSearch(T.left, k)
    else return BSTSearch(T.right, k)
```

### 3.2 插入
**假装去查找 k**；查找走到空子树（树的"边缘"）时，就把 k 放在那里。
```
function BSTInsert(T, k)
    if T = null then
        T ← new node; T.root ← k; T.left ← null; T.right ← null
    else if k < T.root then
        T.left ← BSTInsert(T.left, k)
    else
        T.right ← BSTInsert(T.right, k)
    return T
```

### 手算演示（第 9 周题 61：依次插入 17, 19, 13, 26, 14, 18, 21, 24）

```
            17
          /    \
        13      19
          \    /   \
          14  18    26
                   /
                 21
                   \
                    24
```
过程：17 为根；19 > 17 去右；13 < 17 去左；26 → 17 右 → 19 右；14 → 13 右；18 → 19 左；21 → 26 左；24 → 21 右。

### 3.3 复杂度
- 查找/插入的比较次数 = 路径长度 ≤ 树高 + 1。
- **较平衡**时树高 Θ(log n) ⇒ 查找 **Θ(log n)**。
- **最坏**：按有序顺序插入（如 1, 2, 3, …, n），树退化成一根"棍子"，树高 n − 1 ⇒ 查找 **Θ(n)**，和线性查找一样。
- 解决办法：保持树平衡 ⇒ 下一讲的 AVL 树、2–3 树。

### 3.4 BST 的中序遍历 = 从小到大排好序的序列
（填空题原题："对 BST 做 ___ 遍历会得到有序序列" → **中序 inorder**。）
上面那棵树中序：13 14 17 18 19 21 24 26。

## 考点与易错

1. 预排序套路：**排序 Θ(n log n) + 线性扫描 Θ(n) = Θ(n log n)**。设计题写的时候要写明用哪种排序（如 Mergesort）。
2. BST 左 < 根 < 右，**对每棵子树都成立**（不只是根的直接孩子）。
3. BST 插入一定插在**叶子位置**（空子树处）。
4. BST 最坏 Θ(n)（有序插入导致退化），平衡时 Θ(log n)。
5. BST 中序遍历是有序的。

## 练习

1. 设计 Θ(n log n) 算法：给定两个数组 A[0..n−1] 和 B[0..n−1]，判断它们是否有公共元素。
2. 设计算法：给定数组 A 和数 s，判断是否存在 i ≠ j 使 A[i] + A[j] = s。要求 Θ(n log n)。
3.（第 9 周题 60）给定 n 个互不相同的整数和 n 个格子，格子之间有固定的不等号（如 □ < □ > □ < □ < □），
   设计算法把数填进格子使所有不等式成立。
4. 依次插入 50, 30, 70, 20, 40, 60, 80, 35 构造 BST，写出它的前序和中序遍历，以及树高。
5. 判断真假：在 BST 中，最大元素一定是叶子。

<summary>答案</summary>

1. 把 A 和 B 合并成一个数组 C（2n 个元素），Mergesort(C)，再扫描是否有相邻相等且来自不同数组的元素
   （可以给每个元素带一个标签）。或者：Mergesort(A)，然后对 B 的每个元素在 A 中二分查找：n log n + n log n = Θ(n log n)。
2. Mergesort(A)，然后双指针：i ← 0，j ← n−1；当 i < j 时：和等于 s 返回 True；和小于 s 则 i ← i+1；否则 j ← j−1。
   排序 Θ(n log n) + 扫描 Θ(n)。
3. 先排序。从左到右填格子：若格子后面是 "<"，放入剩余元素中**最小**的；若是 ">"，放入剩余元素中**最大**的；
   最后一个格子放剩下的那个。例：4, 6, 3, 1, 8 与 □<□>□<□<□ → 1 < 8 > 3 < 4 < 6。
   排序 Θ(n log n)，填格 Θ(n)。
4. 树：50 的左 30（左 20，右 40（左 35）），右 70（左 60，右 80）。
   前序 50 30 20 40 35 70 60 80；中序 20 30 35 40 50 60 70 80；树高 3（50→30→40→35）。
5. 假。最大元素是"一直往右走"到底的结点，它没有右孩子，但**可能有左孩子**。
