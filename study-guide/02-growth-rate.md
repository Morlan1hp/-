# 第 2 章（第 3 讲）增长率与算法效率：O、Ω、Θ

> **本章位置**：从这一讲开始，我们要能**精确地说一个算法有多快**。
> 后面每一讲的每个算法都会问"复杂度是多少"，所以这一章是全课的地基。
> **考试比重**：选择题必考（比较增长率、判断 O/Ω/Θ）；设计题每题都要写复杂度。

---

## 1. 怎么衡量"效率"

运行时间取决于：①算法本身 ②输入 ③机器 ④语言/编译器/操作系统。
比较算法时**忽略 ③④**，只数"单位时间"：
- 用自然数 **n** 表示**输入规模**（数组长度、图的结点数和边数……）；
- 把运行时间写成 n 的函数 **t(n)**。

### 1.1 基本操作（Basic Operation）
**对运行时间贡献最大的那个操作**，通常是**最内层循环里最"贵"的操作**。
若基本操作耗时 c，执行 g(n) 次，则 t(n) ≈ c·g(n)。

| 问题 | 输入规模 | 基本操作 |
|---|---|---|
| 在 n 个元素的表中查找 | n | 关键字比较 |
| 两个矩阵相乘 | 矩阵的行列数 | 浮点乘法 |
| 计算 aⁿ | log n（n 的位数） | 浮点乘法 |
| 图问题 | 结点数和边数 | 访问一个结点 |

### 1.2 最好、最坏、平均情况
以线性查找为例（基本操作：比较 `A[j] = x`）：

| 情况 | 输入 | 比较次数 |
|---|---|---|
| 最坏（worst） | x 不在数组里（或在最后） | n |
| 最好（best） | x 在第一个位置 | 1 |
| 平均（average） | 对所有可能输入取期望 | 约 n/2（若 x 一定在数组中且位置均匀） |

> ⚠️ **平均情况不是"最好和最坏的平均值"**，而是对所有规模为 n 的输入求期望。
> **摊还分析（amortised）**：把一串操作的总代价平摊到每次操作上（用于会自我调整的数据结构）。

### 1.3 只有大输入才重要

| n | log₂n | n | n log₂n | n² | n³ | 2ⁿ | n! |
|---|---|---|---|---|---|---|---|
| 10 | 3 | 10 | 3·10 | 10² | 10³ | 10³ | 4·10⁶ |
| 100 | 7 | 10² | 7·10² | 10⁴ | 10⁶ | 10³⁰ | 9·10¹⁵⁷ |
| 1000 | 10 | 10³ | 1·10⁴ | 10⁶ | 10⁹ | — | — |

10³⁰ 纳秒 ≈ 宇宙年龄纳秒数的 1000 倍。指数算法在 n = 100 时就已经完全不可用。

### 1.4 常见复杂度及其典型来源

| 复杂度 | 名称 | 典型场景 |
|---|---|---|
| 1 | 常数 | 与输入无关（数组按下标取值） |
| log n | 对数 | 每步把问题规模减半（二分查找、平衡树查找） |
| n | 线性 | 每个输入处理一次（找最大值） |
| n log n | 线性对数 | 分治排序（归并、堆排序） |
| n² / n³ | 平方 / 立方 | 处理所有的对 / 三元组（两重/三重循环） |
| 2ⁿ | 指数 | 处理所有子集 |
| n! | 阶乘 | 处理所有排列（TSP 暴力） |

猜数字游戏（1..n，每次告诉你大了还是小了）：每次猜中间，范围减半 ⇒ 最坏 log n 次。

## 2. 渐近记号（Asymptotic Notation）

思想：**忽略常数因子，忽略小规模输入**，只看增长速度。

记号 f(n) ≺ g(n) 表示 lim_{n→∞} f(n)/g(n) = 0（g 比 f 增长快）：

```
1 ≺ log n ≺ n^ε ≺ n^c ≺ n^{log n} ≺ cⁿ ≺ nⁿ        （0 < ε < 1 < c）
```

"要往大了想"：log n ≺ n^{0.0001}，虽然 n = 10¹⁰⁰ 时 log₁₀ n = 100 > n^{0.0001} ≈ 1.023，但 n 足够大时一定反超。

### 2.1 大 O（上界）
**定义**：t(n) ∈ O(g(n)) 当且仅当存在正常数 c 和 n₀，使得对所有 n > n₀，有 t(n) < c·g(n)。

直观：t 的增长**不快于** g。
- 3n ∈ O(n) ✔（更精确），3n ∈ O(n²) ✔（也对，但不精确）。
- 课本写 t(n) ∈ O(g(n))；有的书写 t(n) = O(g(n))，意思一样（O 其实是一个**集合**）。

### 2.2 大 Ω（下界）
t(n) ∈ Ω(g(n)) 当且仅当存在 c, n₀，使 n > n₀ 时 t(n) > c·g(n)。t 的增长**不慢于** g。

### 2.3 大 Θ（紧确界）
t(n) ∈ Θ(g(n)) 当且仅当 t(n) ∈ O(g(n)) **且** t(n) ∈ Ω(g(n))。t 与 g **同阶**。

> **答题习惯**：题目问"复杂度是多少"时，尽量给 **Θ**（最精确）；如果只能确定上界，就写 O。

## 3. 用定义证明（讲义原题）

### 例 1：1 + 2 + … + n ∈ O(n²)
要找 c, n₀ 使 n > n₀ 时 1+2+…+n < c·n²。

```
1 + 2 + … + n = n(n+1)/2 = (n² + n)/2
             < n² + n        （n > 0）
             < n² + n²       （n > 1）
             = 2n²
```
取 **c = 2，n₀ = 1**。

### 例 2：17n² + 85n + 1024 ∈ O(n²)
**方法一**：猜 c = 18，需要 85n + 1024 < n²。猜 n₀ = 1024：85·1024 + 1024 = 86·1024 < 1024·1024 ✔。取 c = 18，n₀ = 1024。

**方法二（通用，对任何多项式都管用）**：n > 1 时
17n² + 85n + 1024 < 17n² + 85n² + 1024n² = (17+85+1024)n²，取 c = 1126，n₀ = 1。

> 结论：**多项式的阶 = 最高次项的次数**。aₖnᵏ + … + a₀ ∈ Θ(nᵏ)（aₖ > 0）。

## 考点与易错

1. **基本操作**选最内层循环中最重要的那个（通常是比较）。
2. 平均情况 ≠ (最好 + 最坏)/2。
3. O 是上界：n ∈ O(n²) 是对的！选择题里经常这样设陷阱。Θ 才是"同阶"。
4. log 的底数不影响阶：Θ(log₂ n) = Θ(ln n) = Θ(log₁₀ n)。
5. 2ⁿ⁻¹ 与 2ⁿ 同阶（差常数 2 倍），但 (n−1)! 与 n! **不同阶**（差 n 倍）。
6. (log n)² 比 log(n²) = 2 log n 增长快。

## 练习（来自第 3 周辅导课）

1. 高斯消元约需 n³/3 次乘法。(a) 1000 个方程比 500 个方程慢多少倍？(b) 电脑快了 1000 倍，同样时间能解多大的方程组？
2. 判断每对函数是否同阶，不同阶时谁增长更快：
   (a) n(n+1) 与 2000n² (b) 100n² 与 0.01n³ (c) log₂n 与 ln n
   (d) log₂²n 与 log₂n² (e) 2ⁿ⁻¹ 与 2ⁿ (f) (n−1)! 与 n!
3. 用定义证明 5n + 3 ∈ O(n)，给出 c 和 n₀。
4. 判断真假：(a) n² ∈ O(n³) (b) n² ∈ Ω(n³) (c) n log n ∈ Θ(n) (d) 2ⁿ ∈ O(3ⁿ) (e) 3ⁿ ∈ O(2ⁿ)

<details>
<summary>答案</summary>

1. (a) (1000/500)³ = **8 倍**，与具体数字无关。
   (b) 设新机器同样时间解 m 个：m³/3 = 1000·n³/3 ⇒ m = 10n，**大 10 倍**。
2. (a) 同阶 (b) 0.01n³ 更快 (c) 同阶（底数不影响）
   (d) log₂n² = 2log₂n，与 log₂n 同阶；但 log₂²n 增长更快（比值 → ∞）
   (e) 同阶（2ⁿ = 2·2ⁿ⁻¹） (f) n! 更快（比值 n! / (n−1)! = n → ∞）
3. n > 3 时 5n + 3 < 5n + n = 6n，取 c = 6，n₀ = 3（取 c = 8，n₀ = 1 也行）。
4. (a) 真 (b) 假 (c) 假（n log n 比 n 增长快） (d) 真 (e) 假（(3/2)ⁿ → ∞）
