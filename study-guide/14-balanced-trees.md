# 第 14 章（第 15 讲）平衡树：AVL 树与 2–3 树

> **本章位置**：从这一讲起由 Cezary Kaliszyk 教授授课。BST 不平衡时会退化成 Θ(n)，
> 本讲用两种办法保证 Θ(log n)：
> ①**实例简化**——AVL 树（插入后用旋转恢复平衡）；②**表示变换**——2–3 树（一个结点放多个键）。
> **考试比重**：教授点名的选择题类型："给一棵 BST，变成 AVL 时做了哪种旋转？"
> AVL 逐个插入、2–3 树逐个插入都必须会手算。

---

## 1. AVL 树

（Adelson-Velsky 和 Landis，1962）

### 1.1 平衡因子（balance factor）
> 结点的平衡因子 = **左子树高度 − 右子树高度**。
> 约定：**单个结点高度为 0，空树高度为 −1**。

**AVL 树**：每个结点的平衡因子都是 −1、0 或 1 的 BST。

> ⚠️ 教授特别提醒：计算平衡因子时比较的是**子树的高度**，不是子树的平衡因子！

### 1.2 插入
1. 像普通 BST 一样插到边缘（叶子位置）；
2. 从新结点往上更新高度/平衡因子；
3. 如果出现 +2 或 −2，就在**最低的**（离新结点最近的）不平衡结点处做**旋转**。

### 1.3 四种旋转（以最低的不平衡结点 r 为准）

| r 的平衡因子 | 偏重孩子的平衡因子 | 形状 | 旋转 |
|---|---|---|---|
| +2（左重） | 左孩子 +1 | 左-左，"/" 直线 | **R 旋转**（右旋） |
| −2（右重） | 右孩子 −1 | 右-右，"\\" 直线 | **L 旋转**（左旋） |
| +2（左重） | 左孩子 −1 | 左-右，"<" 折线 | **LR 旋转**（先左后右，双旋） |
| −2（右重） | 右孩子 +1 | 右-左，">" 折线 | **RL 旋转**（先右后左，双旋） |

记忆：**直线单旋，折线双旋**；旋转名字指的是把哪边"转上来"的方向——左重用 R，右重用 L。

**三个键的最小例子**（插入顺序 → 旋转 → 结果都是 2 为根，1、3 为孩子）：

```
R 旋转：3,2,1        L 旋转：1,2,3        LR 旋转：3,1,2       RL 旋转：1,3,2
    3                 1                     3                   1
   /                   \                   /                     \
  2          ⇒          2         ⇒       1            ⇒          3          ⇒
 /                       \                 \                     /
1                         3                 2                   2
                                                         全部变成：   2
                                                                    / \
                                                                   1   3
```

### 1.4 旋转的一般形式

**R 旋转**（r 左重，c 是 r 的左孩子，T1、T2 是 c 的子树，T3 是 r 的右子树）：
```
        r                    c
       / \                 /   \
      c   T3      ⇒       T1    r
     / \                       / \
    T1  T2                    T2  T3
```
c 上来做根，**c 原来的右子树 T2 变成 r 的左子树**。L 旋转是镜像。

**LR 旋转**（r 左重，c 是 r 的左孩子且右重，g 是 c 的右孩子）：
```
        r                       g
       / \                   /     \
      c   T4       ⇒        c       r
     / \                   / \     / \
    T1  g                 T1 T2   T3  T4
       / \
      T2  T3
```
**孙子 g 一下子升到顶上**，c 和 r 分别成为它的左右孩子；g 的左子树给 c，右子树给 r。RL 是镜像。

### 1.5 手算演示（第 9 周题 62：依次插入 A L G O R I T H M）

| 插入 | 发生的事 | 树（括号内为左、右子树） |
|---|---|---|
| A | | A |
| L | | A(−, L) |
| G | A 的 bf = −2，右孩子 L 的 bf = +1 ⇒ **RL 旋转** | G(A, L) |
| O | | G(A, L(−, O)) |
| R | L 的 bf = −2，右孩子 O 的 bf = −1 ⇒ **L 旋转**（在 L 处） | G(A, O(L, R)) |
| I | I 插到 L 左边；G 的 bf = 0 − 2 = −2，右孩子 O 的 bf = +1 ⇒ **RL 旋转**（在 G 处） | L(G(A, I), O(−, R)) |
| T | O 的 bf = −2，右孩子 R 的 bf = −1 ⇒ **L 旋转**（在 O 处） | L(G(A, I), R(O, T)) |
| H | 插到 I 左边，无失衡 | L(G(A, I(H, −)), R(O, T)) |
| M | 插到 O 左边，无失衡 | L(G(A, I(H, −)), R(O(M, −), T)) |

最终：
```
              L
          /       \
         G         R
        / \       / \
       A   I     O   T
          /     /
         H     M
```
（与辅导课答案一致。）

### 1.6 再来一个（包含 LR 和 R）：依次插入 10, 20, 30, 25, 28, 5, 3

| 插入 | 发生的事 | 结果 |
|---|---|---|
| 10, 20, 30 | 10 的 bf = −2，20 的 bf = −1 ⇒ L 旋转 | 20(10, 30) |
| 25 | | 20(10, 30(25, −)) |
| 28 | 28 插在 25 的右边；30 的 bf = +2，左孩子 25 的 bf = −1 ⇒ **LR 旋转**（在 30 处） | 20(10, 28(25, 30)) |
| 5 | | 20(10(5, −), 28(25, 30)) |
| 3 | 10 的 bf = +2，左孩子 5 的 bf = +1 ⇒ **R 旋转**（在 10 处） | 20(5(3, 10), 28(25, 30)) |

注意 28 那一步：根 20 的 bf 只是 −2 吗？算一下：左子树 10 高度 0，右子树（30→25→28）高度 2，bf = −2！
但**最低的**不平衡结点是 30（bf = +2），只需在 30 处旋转，旋转后 20 自然恢复平衡。

### 1.7 AVL 性质
- n 个结点的 AVL 树深度 **Θ(log n)**（随机数据接近 log₂n）。
- 查找、插入 **Θ(log n)**；删除也是 Θ(log n)（但实现更复杂）。

## 2. 其他平衡树（了解即可）

- **红黑树（red-black tree）**：结点涂红/黑，①红结点没有红孩子；②根到每个边缘的路径上黑结点数相同。最长路径至多是最短路径的 2 倍。
- **伸展树（splay tree）**：自调整、自适应，经常访问的元素被移到靠近根的位置。
- 表示变换类：2–3 树、2–3–4 树、B 树。

## 3. 2–3 树（Hopcroft，1970）

**思想**：一个结点可以放 1 个或 2 个键。
- **2-结点**：1 个键 n，2 个孩子（左 < n < 右）。
- **3-结点**：2 个键 m < n，3 个孩子（左 < m < 中 < n < 右）。

**核心性质：完美平衡——所有叶子都在同一层。**
（2–3–4 树还允许有 3 个键 4 个孩子的 4-结点。）

### 3.1 插入
1. 假装查找 k，走到应该放 k 的**叶子**；
2. 叶子是 2-结点 ⇒ 直接放进去，变成 3-结点；
3. 叶子是 3-结点 ⇒ 暂时放进去变成 3 个键 k₁ < k₂ < k₃，然后**分裂**：
   k₁、k₃ 各自成为一个 2-结点，**中间的 k₂ 上升到父结点**；
4. 父结点也可能因此溢出，**同样分裂**，一直向上；
5. 根分裂时产生新根 ⇒ **树高加 1**（这是 2–3 树长高的唯一方式，所以叶子始终同层）。

### 3.2 手算演示（讲义：依次插入 9, 5, 8, 3, 2, 4, 7）

记号：`[键]` 表示结点，冒号后是孩子。

| 插入 | 过程 | 树 |
|---|---|---|
| 9 | | [9] |
| 5 | | [5,9] |
| 8 | [5,8,9] 溢出，8 上升成新根 | [8: [5] [9]] |
| 3 | | [8: [3,5] [9]] |
| 2 | 叶子 [2,3,5] 溢出，3 上升 | [3,8: [2] [5] [9]] |
| 4 | | [3,8: [2] [4,5] [9]] |
| 7 | 叶子 [4,5,7] 溢出，5 上升 ⇒ 父 [3,5,8] 溢出，5 再上升成新根 | [5: [3: [2] [4]] [8: [7] [9]]] |

```
          5
        /   \
       3     8
      / \   / \
     2   4 7   9
```

### 3.3 手算演示（讲义练习：C, O, M, P, U, T, I, N, G；C < G < I < M < N < O < P < T < U）

| 插入 | 过程 | 树 |
|---|---|---|
| C, O | | [C,O] |
| M | [C,M,O] 溢出，M 上升 | [M: [C] [O]] |
| P | | [M: [C] [O,P]] |
| U | [O,P,U] 溢出，P 上升 | [M,P: [C] [O] [U]] |
| T | | [M,P: [C] [O] [T,U]] |
| I | | [M,P: [C,I] [O] [T,U]] |
| N | | [M,P: [C,I] [N,O] [T,U]] |
| G | [C,G,I] 溢出，G 上升 ⇒ [G,M,P] 溢出，M 上升成新根 | [M: [G: [C] [I]] [P: [N,O] [T,U]]] |

```
             M
          /     \
         G       P
        / \    /   \
       C   I  N,O  T,U
```

### 3.4 第 9 周题 64：A L G O R I T H M
结果：[I: [G: [A] [H]] [O: [L,M] [R,T]]]
```
            I
         /     \
        G       O
       / \    /   \
      A   H  L,M  R,T
```

### 3.5 高度分析（n 为键的个数，h 为树高）
- **最坏（最高）**：全是 2-结点，n = 1 + 2 + 4 + … + 2ʰ = 2^{h+1} − 1 ⇒ h = log₂(n+1) − 1。
- **最好（最矮）**：全是 3-结点，n = 2(1 + 3 + … + 3ʰ) = 3^{h+1} − 1 ⇒ h = log₃(n+1) − 1。
- 所以 **log₃(n+1) − 1 ≤ h ≤ log₂(n+1) − 1**，查找、插入都是 **Θ(log n)**。

## 考点与易错

1. 平衡因子 = 左高 − 右高；空树高 −1，叶子高 0；**比较高度，不比较平衡因子**。
2. 在**最低的**失衡结点旋转。
3. 失衡结点 +2 且左孩子 +1 ⇒ R；+2 且左孩子 −1 ⇒ LR；−2 且右孩子 −1 ⇒ L；−2 且右孩子 +1 ⇒ RL。
4. 双旋后**孙子结点**成为新子树的根。
5. 2–3 树：插入永远在叶子；溢出就分裂，**中间键上升**；只有根分裂时树才长高；所有叶子同层。
6. 2–3 树中 n 个键的高度在 log₃(n+1) − 1 和 log₂(n+1) − 1 之间。

## 练习

1. 判断插入以下序列时第一次发生的旋转类型：(a) 50, 40, 45 (b) 50, 60, 70 (c) 50, 60, 55 (d) 50, 40, 30
2.（第 9 周题 63）键 k₁ < k₂ < k₃ < k₄ < k₅ 的 120 种插入顺序中，恰有两种会"先发生 LR 旋转，再发生 RL 旋转"。是哪两种？
3. 依次向空 AVL 树插入 1, 2, 3, 4, 5, 6, 7，画出最终的树。
4.（第 9 周题 65）依次插入 1, 2, 3, 4, 5 和 2, 3, 4, 5, 1 构造 2–3 树，两棵树一样吗？这 5 个键一共能构成几种不同的 2–3 树？
5. 一棵高度为 2 的 2–3 树最少和最多能存多少个键？

<details>
<summary>答案</summary>

1. (a) 50 bf=+2，左孩子 40 bf=−1 ⇒ LR (b) L (c) RL (d) R
2. 前三个键插入后必须发生 LR 且得到完全平衡的三结点树，后两个键必须引起 RL：**3, 1, 2, 5, 4** 和 **5, 1, 4, 3, 2**。
   - 3,1,2：LR → 2(1,3)；5、4：3(−,5(4)) 在 3 处 RL → 2(1, 4(3,5))。
   - 5,1,4：LR → 4(1,5)；3、2：1(−,3(2)) 在 1 处 RL → 4(2(1,3), 5)。
3. 1,2,3 → L 旋转得 2(1,3)；4；5 → 在 3 处 L 旋转得 2(1,4(3,5))；6 → 根 2 失衡（bf=−2，右孩子 4 bf=−1），在 2 处 L 旋转得 4(2(1,3),5(−,6))；
   7 → 在 5 处 L 旋转。最终是完全平衡树：**4(2(1,3), 6(5,7))**。
4. 1..5 得 [2,4: [1] [3] [5]]；2,3,4,5,1 得 [3: [1,2] [4,5]]。**不一样**。5 个键只有这 **2 种** 2–3 树。
5. 高度 2 有 3 层。最少：全 2-结点，1+2+4 = **7** 个键；最多：全 3-结点，2+6+18 = **26** 个键。
