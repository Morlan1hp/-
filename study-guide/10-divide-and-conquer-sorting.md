## 1. 分治法三步

1. **分（Divide）**：把问题实例分成若干个更小的实例（最好规模相等）；
2. **治（Conquer）**：递归地解决小实例；
3. **合（Combine）**：把小实例的解合并成原问题的解。

与减治的区别：减治只解**一个**子问题；分治通常要解**多个**子问题再合并。

## 2. 分治递推式与主定理（Master Theorem）

把规模 n 的问题分成 b 个规模 n/b 的子问题，其中 a 个需要求解，划分与合并的代价是 f(n)：

```
T(n) = a·T(n/b) + f(n)
```

**主定理**：设整数常数 a ≥ 1，b > 1，f(n) ∈ Θ(n^d)，d ≥ 0，则

```
         ⎧ Θ(n^d)            若 a < b^d
T(n) ∈   ⎨ Θ(n^d · log n)    若 a = b^d
         ⎩ Θ(n^{log_b a})    若 a > b^d
```
（a 可以大于 b。）

**使用步骤**：①从递推式读出 a、b、d；②计算 b^d 并与 a 比较；③套公式。

### 讲义例题

| 递推式 | a | b | d | b^d | 比较 | 结果 |
|---|---|---|---|---|---|---|
| T(n) = T(n/2) + 1 | 1 | 2 | 0 | 1 | a = b^d | Θ(log n)（二分查找） |
| T(n) = 2T(n/2) + n | 2 | 2 | 1 | 2 | a = b^d | Θ(n log n)（归并排序） |
| T(n) = 4T(n/4) + n | 4 | 4 | 1 | 4 | a = b^d | Θ(n log n) |
| T(n) = T(n/2) + n | 1 | 2 | 1 | 2 | a < b^d | Θ(n) |
| T(n) = 2T(n/2) + n² | 2 | 2 | 2 | 4 | a < b^d | Θ(n²) |
| T(n) = 4T(n/2) + n | 4 | 2 | 1 | 2 | a > b^d | Θ(n^{log₂4}) = Θ(n²) |
| T(n) = 4T(n/2) + n² | 4 | 2 | 2 | 4 | a = b^d | Θ(n² log n) |
| T(n) = 4T(n/2) + n³ | 4 | 2 | 3 | 8 | a < b^d | Θ(n³) |
| T(n) = 2T(n/2) + 1 | 2 | 2 | 0 | 1 | a > b^d | Θ(n^{log₂2}) = Θ(n) |

### 用倒推法验证 T(n) = 2T(n/2) + n
```
T(n) = 2T(n/2) + n
     = 4T(n/4) + 2(n/2) + n = 4T(n/4) + 2n
     = 8T(n/8) + 3n
     = … = 2ᵏ T(n/2ᵏ) + k·n         （k = log₂n 时 n/2ᵏ = 1）
     = n·T(1) + n log₂n ∈ Θ(n log n)
```
直观理解：递归树每层总工作量都是 n，共 log n 层。

**主定理不适用的情况**：T(n) = T(n−1) + n（不是 n/b 形式）、f(n) = n log n（不是 n^d 形式）等，
这些要用倒推法。

## 3. 归并排序（Mergesort）

**思想**：把数组切成两半，分别排序，再**合并**两个有序数组。

```
function Mergesort(A[0..n−1])
    if n > 1 then
        B[0..⌊n/2⌋−1] ← A[0..⌊n/2⌋−1]          ▷ 复制左半
        C[0..⌈n/2⌉−1] ← A[⌊n/2⌋..n−1]           ▷ 复制右半
        Mergesort(B)
        Mergesort(C)
        Merge(B, C, A)

function Merge(B[0..p−1], C[0..q−1], A[0..p+q−1])
    i ← 0; j ← 0; k ← 0
    while i < p and j < q do
        if B[i] ≤ C[j] then              ▷ 相等时取 B（左边）⇒ 稳定
            A[k] ← B[i]; i ← i + 1
        else
            A[k] ← C[j]; j ← j + 1
        k ← k + 1
    if i = p then
        copy C[j..q−1] to A[k..p+q−1]
    else
        copy B[i..p−1] to A[k..p+q−1]
```

### 合并演示（讲义）
B = 2 3 8 9，C = 1 4 5 7：
1 (C) → 2 (B) → 3 (B) → 4 (C) → 5 (C) → 7 (C) → C 用完，把 B 剩下的 8 9 复制过去。
A = 1 2 3 4 5 7 8 9，共 6 次比较。

### 完整演示（第 7 周题 44：S O R T X A M P L E）
n = 10，左半 SORTX，右半 AMPLE（每次左半 = ⌊n/2⌋ 个）：

```
                    S O R T X A M P L E
             S O R T X              A M P L E
          S O     R T X          A M     P L E
         S   O   R   T X        A   M   P   L E
                     T   X                  L   E
合并：
         O S         T X         A M          E L
                   R T X                    E L P
            O R S T X                 A E L M P
                    A E L M O P R S T X
```

### 复杂度
合并 ⌊n/2⌋ 和 ⌈n/2⌉ 个元素，最坏比较 n − 1 次（最大和次大分属两边时）：
C(n) = 2C(n/2) + (n − 1)，C(1) = 0 ⇒ 由主定理 **Θ(n log n)**。
最好、最坏、平均**都是 Θ(n log n)**。大 n 时比较次数约为最坏情况的 75%。

### 性质
- **不是原地的 ✘**：需要 Θ(n) 额外空间（数组 B、C）。
- **稳定 ✔**：合并时 `B[i] ≤ C[j]` 取左边，相等元素保持原顺序。
- 链表排序、超大数据（外部排序）的首选。
- **自底向上归并**：先两两合并成长度 2 的有序段，再合并成长度 4、8……（不用递归）。

## 4. 快速排序（Quicksort）

**思想**：用划分把数组分成"≤ p | p | ≥ p"，p 已在最终位置，再递归排序左右两段。
（归并是"分容易、合费劲"；快排是"分费劲、合不用做"。）

```
function Quicksort(A[lo..hi])
    if lo < hi then
        s ← HoarePartition(A[lo..hi])
        Quicksort(A[lo..s−1])
        Quicksort(A[s+1..hi])
```
初始调用 Quicksort(A[0..n−1])。

### 4.1 Hoare 划分（课上的标准版本）

```
function HoarePartition(A[lo..hi])
    p ← A[lo]
    i ← lo; j ← hi + 1
    repeat
        repeat i ← i + 1 until A[i] ≥ p      ▷ 从左找 ≥ p 的（不能越过 hi）
        repeat j ← j − 1 until A[j] ≤ p      ▷ 从右找 ≤ p 的
        swap(A[i], A[j])
    until i ≥ j
    swap(A[i], A[j])                         ▷ 撤销最后一次多余的交换
    swap(A[lo], A[j])                        ▷ pivot 归位
    return j
```

**手算口诀**：i 从左往右找"**大于等于** p"的，j 从右往左找"**小于等于** p"的；
i < j 就交换并继续；i ≥ j（两指针交错）就停，把 pivot 与 A[j] 交换。

**手算演示（讲义）**：A = 9 23 8 41 22 3 37，p = 9
1. i 停在 23（下标 1），j 停在 3（下标 5），i < j，交换 → 9 **3** 8 41 22 **23** 37
2. i 停在 41（下标 3），j 停在 8（下标 2），i ≥ j，停止（不交换）
3. 交换 A[0] 与 A[j] = A[2] → **8 3 9 41 22 23 37**，返回 s = 2

接着递归：[8 3] → 3 8；[41 22 23 37]（p = 41，i 一直走到末尾，j 停在 37）→ 37 22 23 41；
[37 22 23] → 23 22 37；[23 22] → 22 23。最终 3 8 9 22 23 37 41。

**手算演示（第 7 周题 45：S O R T X A M P L E）**

| 子数组 | pivot | 划分结果 | s |
|---|---|---|---|
| S O R T X A M P L E | S | P O R E L A M **S** X T | 7 |
| P O R E L A M | P | A O M E L **P** R | 5 |
| A O M E L | A | **A** O M E L | 0 |
| O M E L | O | L M E **O** | 4 |
| L M E | L | E **L** M | 2 |
| X T | X | T **X** | 9 |

第一行细节：i 停在 T，j 停在 E，交换 → S O R E X A M P L T；i 停在 X，j 停在 L，交换 → S O R E L A M P X T；
i 停在 X（下标 8），j 停在 P（下标 7），交错，停止；交换 S 与 P。
最终：A E L M O P R S T X。

### 4.2 复杂度

| 情况 | 何时发生 | 递推式 | 结果 |
|---|---|---|---|
| 最好 | pivot 每次都是中位数，两边等分 | C(n) = 2C(n/2) + n | Θ(n log n) |
| 最坏 | **数组已经有序**（或逆序），每次只减少 1 | C(n) = C(n−1) + n | n + (n−1) + … + 2 ∈ Θ(n²) |
| 平均 | 随机数据 | — | Θ(n log n)，约 1.38 n log₂n 次比较 |

### 4.3 改进
- **三数取中（median-of-three）**：取 A[lo]、A[⌊(lo+hi)/2⌋]、A[hi] 的中位数做 pivot。
  对已排序数组，这正好取到真正的中位数 ⇒ 有序数组反而变成**最好情况**（第 7 周题 47）。
- **随机选 pivot**。
- **提前截断（early cut-off）**：子数组很小时（如 < 10）停止递归，最后对整个数组做一次插入排序（几乎有序 ⇒ 很快）。

### 4.4 性质
- **原地 ✔**（只用递归栈）。
- **不稳定 ✘**：例如 [3, 1ᵃ, 1ᵇ, 5]，p = 3：i 停在 5，j 停在 1ᵇ，交错；pivot 与 A[2] = 1ᵇ 交换 → [1ᵇ, 1ᵃ, 3, 5]，两个 1 的顺序反了。
- 随机数据上公认**最快**的排序（内循环非常紧凑）。虽然归并排序有更好的最坏保证，快排平均更快。

## 5. 排序算法对比（到目前为止）

| 算法 | 最好 | 平均 | 最坏 | 原地 | 稳定 |
|---|---|---|---|---|---|
| 选择排序 | n² | n² | n² | ✔ | ✘ |
| 插入排序 | **n** | n² | n² | ✔ | ✔ |
| 希尔排序 | — | ~n^1.25 | n^1.5 | ✔ | ✘ |
| 归并排序 | n log n | n log n | n log n | ✘ | ✔ |
| 快速排序 | n log n | n log n | **n²** | ✔ | ✘ |
| （堆排序，第 12 章） | n log n | n log n | n log n | ✔ | ✘ |

## 考点与易错

1. 主定理：先算 b^d 再和 a 比；a > b^d 时结果是 n^{log_b a}（**不是** n^d）。
2. 归并：不原地、稳定、所有情况 Θ(n log n)；合并时相等取左边。
3. 快排（Hoare）：i 找 ≥ p，j 找 ≤ p；交错后 swap(A[lo], A[j])；原地、不稳定；有序输入是最坏 Θ(n²)。
4. 三数取中让有序输入变为最好情况。
5. 追踪题要写出每次划分后的**整个子数组**以及 s。

5. 归并排序和快速排序，哪个适合给**链表**排序？哪个适合内存很紧张的情况？

<summary>答案</summary>

1. (a) a=4, b^d=2，a > b^d ⇒ Θ(n^{log₂4}) = Θ(n²) (b) a = b^d = 4 ⇒ Θ(n² log n) (c) a=4 < 8 ⇒ Θ(n³)
2. 3T(n/3)+1：a=3 > 3⁰=1 ⇒ Θ(n^{log₃3}) = Θ(n)。
   8T(n/2)+n²：a=8 > 4 ⇒ Θ(n³)。7T(n/2)+n²：a=7 > 4 ⇒ Θ(n^{log₂7}) ≈ Θ(n^2.81)（Strassen 矩阵乘法）。
3. [5 3 1 9 8 2 4 7] p=5：i 停 9，j 停 4，交换 → 5 3 1 4 8 2 9 7；i 停 8，j 停 2，交换 → 5 3 1 4 2 8 9 7；
   i 停 8（下标 5），j 停 2（下标 4），交错；交换 5 和 2 → **2 3 1 4 5 8 9 7**，s=4。
   [2 3 1 4] p=2：i 停 3，j 停 1，交换 → 2 1 3 4；i 停 3，j 停 1，交错；交换 → **1 2 3 4**，s=1。
   [3 4] p=3 → 3 4 不变。[8 9 7] p=8：i 停 9，j 停 7，交换 → 8 7 9；交错后交换 8 与 7 → **7 8 9**。
   结果 1 2 3 4 5 7 8 9。
4. 改造归并排序，让它返回逆序对个数。合并时如果 C[j] < B[i]，那么 B[i..p−1] 这 p − i 个元素都比 C[j] 大，
   都和 C[j] 构成逆序对：
   ```
   function CountInv(A[0..n−1])            ▷ 返回逆序对数，并把 A 排好序
       if n ≤ 1 then return 0
       copy A[0..⌊n/2⌋−1] to B; copy A[⌊n/2⌋..n−1] to C
       x ← CountInv(B); y ← CountInv(C)
       return x + y + MergeCount(B, C, A)

   function MergeCount(B[0..p−1], C[0..q−1], A)
       i ← 0; j ← 0; k ← 0; res ← 0
       while i < p and j < q do
           if B[i] ≤ C[j] then
               A[k] ← B[i]; i ← i + 1
           else
               res ← res + (p − i)
               A[k] ← C[j]; j ← j + 1
           k ← k + 1
       copy the remaining elements of B or C to A
       return res
   ```
   T(n) = 2T(n/2) + Θ(n) ⇒ Θ(n log n)。
5. 链表：**归并排序**（只需改指针，不需要随机访问，也不需要额外数组）。内存紧张：**快排**或堆排序（原地）。
