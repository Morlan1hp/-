# 第 19 章（第 20 讲）贪心算法：Prim 最小生成树与 Dijkstra 最短路径

> **本章位置**：最后一种设计策略——贪心（Greedy）：每一步都做**当前看来最好**的选择，并且不回头。
> 本讲两个经典贪心算法都用到第 12 章的**堆（优先队列）**。
> **考试比重**：Prim、Dijkstra 的手算表格非常常考；"贪心何时失败"（举反例）也常考。
> ⚠️ Kruskal **不考**。

---

## 1. 贪心思想

- 每一步基于**局部最优**做决定；
- 局部最优**不一定**带来全局最优；
- 但有些著名问题的贪心算法**既正确又快**（Prim、Dijkstra、哈夫曼）；
- 对困难问题，贪心有时能给出可接受的**近似解**。

### 例：找零
面值 25、10、1 分，凑 35 分：贪心先尽量用 25，再用 10……得 25 + 10，2 枚，最优。
讲义问题：哪个金额贪心会失败？(a) 50 (b) 30 (c) 5
答：**(b) 30**。贪心：25 + 1×5 = 6 枚；最优：10×3 = 3 枚。

### 贪心失败的经典反例（第 12 周题 80、81）
- **背包按"性价比"贪心**：W = 8，物品 (价值, 重量)：(6, 5)、(4, 4)、(3, 4)。性价比最高的是第一个，选了它就装不下别的，总价值 6；
  但选后两个总价值 7。⇒ 0/1 背包不能贪心（要用 DP）。
- **连线问题**：直线上 n 个白点 n 个黑点，按"先连所有长度 1 的，再连长度 2 的……"贪心，
  对 □□■■□□■■ 会用掉长度 10 的线，而最优只要 8。（正确做法：用栈从左到右扫描，遇到与栈顶颜色相反的点就配对弹栈，否则入栈。）

> 设计题里想用贪心，**最好能说明它为什么对**；如果说不清，考虑 DP。

## 2. 最小生成树（Minimum Spanning Tree, MST）

- **树**：连通且无环的图。
- 图 ⟨V, E⟩ 的**生成树**：一棵树 ⟨V, E′⟩，其中 E′ ⊆ E（包含所有结点，只用原图的部分边）。
- **最小生成树**：带权连通图的所有生成树中，**边权总和最小**的那一棵。
- 应用：用最少的电缆连接所有城市、网络设计。

## 3. Prim 算法

**思想**：从任意一个结点开始，维护一棵不断长大的树 T。每一步把**离树最近**的树外结点（通过一条最小权边）连进来。
重复 |V| − 1 次。

```
function Prim(⟨V, E⟩)
    V_T ← {v₀}
    E_T ← ∅
    for i ← 1 to |V| − 1 do
        find a minimum-weight edge (v, u) ∈ V_T × (V \ V_T)
        V_T ← V_T ∪ {u}
        E_T ← E_T ∪ {(v, u)}
    return E_T
```

### 用优先队列（最小堆）实现
cost[w] = 目前树外结点 w 连到树上的最小边权；prev[w] = 那条边在树上的端点。

```
function Prim(⟨V, E⟩)
    for each v ∈ V do
        cost[v] ← ∞
        prev[v] ← nil
    pick an initial node v₀
    cost[v₀] ← 0
    Q ← InitPriorityQueue(V)              ▷ 优先级 = cost，最小堆
    while Q is non-empty do
        u ← EjectMin(Q)                   ▷ u 加入树（边 prev[u]–u 加入 MST）
        for each (u, w) ∈ E do
            if w ∈ Q and weight(u, w) < cost[w] then
                cost[w] ← weight(u, w)
                prev[w] ← u
                Update(Q, w, cost[w])     ▷ 调整 w 在堆中的位置
```

### 手算演示（讲义）
无向边：a-b 5, a-c 6, a-d 4, b-c 1, b-d 2, c-d 2, c-e 5, c-f 3, d-f 4, e-f 4。从 a 开始。表中 "cost/prev"：

| 树中结点 | b | c | d | e | f |
|---|---|---|---|---|---|
| a | 5/a | 6/a | **4/a** | ∞/nil | ∞/nil |
| a, d | **2/d** | 2/d | | ∞/nil | 4/d |
| a, d, b | | **1/b** | | ∞/nil | 4/d |
| a, d, b, c | | | | 5/c | **3/c** |
| a, d, b, c, f | | | | **4/f** | |
| a, d, b, c, f, e | | | | | |

每行选 cost 最小的（粗体）加入树；平局按字母序（b 和 c 都是 2，选 b）。
加入一个结点后，只更新它的邻居：例如加入 d 后，b 从 5 降为 2，c 从 6 降为 2，f 从 ∞ 降为 4。
**MST 边**：a-d(4), d-b(2), b-c(1), c-f(3), f-e(4)，**总权 14**。

### 手算演示（第 12 周题 82）
边：a-b 2, a-c 4, a-d 1, b-d 3, b-e 9, c-d 2, c-f 5, d-e 7, d-f 8, d-g 4, e-g 6, f-g 1。从 a 开始：

| 树中结点 | b | c | d | e | f | g |
|---|---|---|---|---|---|---|
| a | 2/a | 4/a | **1/a** | ∞ | ∞ | ∞ |
| a, d | **2/a** | 2/d | | 7/d | 8/d | 4/d |
| a, d, b | | **2/d** | | 7/d | 8/d | 4/d |
| a, d, b, c | | | | 7/d | 5/c | **4/d** |
| a, d, b, c, g | | | | 6/g | **1/g** | |
| a, d, b, c, g, f | | | | **6/g** | | |

加入顺序：a-d(1), a-b(2), d-c(2), d-g(4), g-f(1), g-e(6)，**总权 16**。

### 复杂度
- 朴素实现（每次扫描所有边找最小）：O(|V|·|E|)。
- **邻接表 + 最小堆**：|V| − 1 次删除最小 + 最多 |E| 次更新优先级，每次 O(log |V|)：
  (|V| − 1 + |E|)·O(log |V|) = **O(|E| log |V|)**（连通图中 |V| − 1 ≤ |E|）。

（Kruskal 算法：另一种贪心 MST 算法，按边权从小到大加边、不成环就加；稀疏图上更好。**不考**。）

## 4. Dijkstra 算法：单源最短路径

- 求**一个固定起点**到所有其他结点的最短路径；有向/无向图都可以；**边权必须非负**。
- 复杂度与 Prim 相同：**O(|E| log |V|)**（对比 Floyd 的 O(|V|³) 求所有点对）。
- 结构和 Prim **几乎一样**，唯一区别：优先级是"**从起点出发的总距离**"，而不是"一条边的权"。

```
function Dijkstra(⟨V, E⟩, v₀)
    for each v ∈ V do
        dist[v] ← ∞
        prev[v] ← nil
    dist[v₀] ← 0
    Q ← InitPriorityQueue(V)              ▷ 优先级 = dist
    while Q is non-empty do
        u ← EjectMin(Q)                   ▷ u 的最短距离确定了
        for each (u, w) ∈ E do
            if dist[u] + weight(u, w) < dist[w] then
                dist[w] ← dist[u] + weight(u, w)
                prev[w] ← u
                Update(Q, w, dist[w])
```

**Prim 与 Dijkstra 唯一的区别**：
| | Prim | Dijkstra |
|---|---|---|
| 比较 | weight(u, w) < cost[w] | **dist[u] +** weight(u, w) < dist[w] |
| 含义 | w 到**树**的最近距离 | w 到**起点**的最短距离 |

### 手算演示（讲义）
无向边：a-c 4, a-d 1, b-d 2, c-d 1, c-e 2, c-f 3, d-e 4, d-f 5。起点 a。表中 "dist/prev"：

| 已确定 | b | c | d | e | f |
|---|---|---|---|---|---|
| a | ∞/nil | 4/a | **1/a** | ∞/nil | ∞/nil |
| a, d | 3/d | **2/d** | | 5/d | 6/d |
| a, d, c | **3/d** | | | 4/c | 5/c |
| a, d, c, b | | | | **4/c** | 5/c |
| a, d, c, b, e | | | | | **5/c** |

加入 d（距离 1）后：b = 1+2 = 3，c = min(4, 1+1) = 2，e = 1+4 = 5，f = 1+5 = 6。
加入 c（距离 2）后：e = min(5, 2+2) = 4，f = min(6, 2+3) = 5。
**结果**：a 0, b 3, c 2, d 1, e 4, f 5。

**还原路径**：沿 prev 往回走。f 的 prev 是 c，c 的是 d，d 的是 a ⇒ 路径 a → d → c → f。
所有 prev 边构成的树叫**最短路径树**。

### 手算演示（第 12 周题 83：同题 82 的图，起点 e）

| 已确定 | a | b | c | d | f | g |
|---|---|---|---|---|---|---|
| e(0) | ∞ | 9/e | ∞ | 7/e | ∞ | **6/e** |
| g(6) | ∞ | 9/e | ∞ | **7/e** | 7/g | |
| d(7) | 8/d | 9/e | 9/d | | **7/g** | |
| f(7) | **8/d** | 9/e | 9/d | | | |
| a(8) | | **9/e** | 9/d | | | |
| b(9) | | | **9/d** | | | |

结果：a 8, b 9, c 9, d 7, e 0, f 7, g 6。
e 到 b 的最短路径是直接的边 e-b（9），但这条边**不在** MST 中——**最短路径树不一定是最小生成树**。

### 负权
Dijkstra 在有负权边时**可能出错**：
例：a→b 3，a→c 4，c→b −2。Dijkstra 先确定 b 的距离为 3，但实际 a→c→b = 2。
- **Bellman-Ford** 算法可以处理任意权值（更慢）。
- 如果有**总权为负的环**，最短路径无意义。

---

## 考点与易错

1. 贪心 = 局部最优，不回头；不一定全局最优（找零 30、0/1 背包是反例）。
2. Prim 加入**离树最近**的点（比较边权）；Dijkstra 加入**离起点最近**的点（比较 dist[u] + 边权）。
3. 手算表格：每行先选最小的确定下来，再**只更新它的邻居**；已确定的点不再改变。注意平局规则（通常按字母序）。
4. 两者用堆都是 O(|E| log |V|)。
5. Dijkstra 要求**非负权**。
6. 最短路径树 ≠ 最小生成树。
7. Prim 的 MST 总权值是唯一的（边权互异时 MST 唯一），但 Prim 的起点不同、平局选择不同，加边顺序可能不同。
