# 第 6 章（第 7 讲）图与图的基本概念（Graphs）

> **本章位置**：图是本课最重要的建模工具。第 8 讲的遍历、第 19 讲的 Warshall/Floyd、
> 第 20 讲的 Prim/Dijkstra 都建立在本章之上。设计题里**把问题建模成图**是极常用的套路。

---

## 1. 定义

图 G = ⟨V, E⟩：
- V：结点（node / vertex）集合；
- E：边（edge）集合，是 V 上的二元关系。(u, v) ∈ E 表示有一条从 u 到 v 的边。

| 概念 | 含义 |
|---|---|
| 无向图（undirected） | 边没有方向；E 是对称的（(u,v) ∈ E ⇔ (v,u) ∈ E） |
| 有向图（directed） | 每条边有方向 |
| 相邻（adjacent）/ 邻居 | (u, v) ∈ E |
| 关联（incident） | 边 (u, v) 关联 u 和 v |
| 度（degree） | 与结点关联的边数。有向图分**入度**（指向它的边数）和**出度**（从它出发的边数） |
| 路径（path） | 结点序列 v₀, v₁, …, vₖ，每个 (vᵢ, vᵢ₊₁) ∈ E；**长度为 k（边数）** |
| 简单路径（simple path） | 没有重复结点 |
| 环 / 回路（cycle） | 起点 = 终点，且不重复走同一条边的路径 |
| 连通（connected） | 无向图中任意两点之间都有路径 |
| 连通分量（component） | 极大连通子图 |
| 带权图（weighted） | 每条边有权值（距离、费用、拥塞……） |
| 稠密 / 稀疏（dense / sparse） | 边数接近 \|V\|² / 边数远小于 \|V\|² |
| 有环 / 无环（cyclic / acyclic） | 有向无环图简称 **DAG**（dag） |
| （自由）树（free tree） | **连通且无环**的无向图；n 个结点恰有 n − 1 条边 |
| 有根树（rooted tree） | 指定一个结点为根，其他结点都从根可达；删掉根剩下若干子树 |

## 2. 用图建模（设计题必备技能）

- **调度问题**：结点 = 任务，有向边 a → b 表示"a 必须在 b 之前完成"。图必须是 **DAG**（有环就无解）。→ 第 8 讲拓扑排序。
- **婚礼座位安排**：结点 = 客人，边 = "这两人不能坐同一桌"。k 张桌子 ⇔ 用 k 种颜色给结点着色，使相邻结点颜色不同（**图的 k-着色问题**）。
- **地图着色**：结点 = 国家，边 = 有公共边界。
- **地铁路线**：结点 = 站，边 = 两站直接相连，权值 = 时间。
- **社交网络、网页排名、基因调控网络、神经网络**……都是图。

## 3. 图的两种表示

用下面这个无向图举例（第 5 周题 27）：

```
    a — b
     \  |
       c — d
        \  |
          e        边：a-b, a-c, b-c, c-d, c-e, d-e
```

### 3.1 邻接矩阵（Adjacency Matrix）
n×n 矩阵，A[u, v] = 1 当且仅当 (u, v) ∈ E。

|   | a | b | c | d | e |
|---|---|---|---|---|---|
| a | 0 | 1 | 1 | 0 | 0 |
| b | 1 | 0 | 1 | 0 | 0 |
| c | 1 | 1 | 0 | 1 | 1 |
| d | 0 | 0 | 1 | 0 | 1 |
| e | 0 | 0 | 1 | 1 | 0 |

- 无向图的矩阵**关于主对角线对称**。
- 带权图：A[u, v] = 权值，无边记为 ∞（Floyd 算法会用）。

### 3.2 邻接表（Adjacency List）
一个数组，每个结点对应一个链表，存它的所有邻居（通常按字母序）：

```
a → b → c
b → a → c
c → a → b → d → e
d → c → e
e → c → d
```
无向图中每条边出现两次。

### 3.3 怎么选？

| | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | Θ(\|V\|²) | Θ(\|V\| + \|E\|) |
| 查询"(u,v) 是否是边" | **O(1)** | O(deg(u)) |
| 枚举 u 的所有邻居 | Θ(\|V\|) | Θ(deg(u)) |
| 遍历整个图（DFS/BFS） | Θ(\|V\|²) | Θ(\|V\| + \|E\|) |
| 适合 | **稠密图** | **稀疏图** |

---

## 考点与易错

1. 路径**长度 = 边数**，不是结点数。
2. 树 = 连通 + 无环；n 个结点的树有 n − 1 条边。
3. 邻接矩阵 Θ(V²) 空间，判边 O(1)；邻接表 Θ(V+E) 空间，适合稀疏图。
4. 无向图邻接矩阵对称；对角线上有 1 表示有自环（loop）。
5. 建模时要说清楚：结点是什么、边是什么、有没有方向、有没有权值。

## 练习

1.（第 3 周题 7）怎样从无向图的邻接矩阵看出：(a) 它是完全图？(b) 有自环？(c) 有孤立结点？
2. 一个有 1000 个结点、2000 条边的图，用哪种表示更省空间？大约各需要多少个存储单元？
3. 有向图 a→b, a→c, b→c, c→a 的邻接矩阵是什么？它是 DAG 吗？各结点的入度和出度是多少？
4. 课程安排：COMP1 是 COMP2 和 COMP3 的先修课，COMP2 和 COMP3 是 COMP4 的先修课。怎么建模？问"能不能一学期只修一门、修完所有课"等价于图的什么性质？

<details>
<summary>答案</summary>

1. (a) 除主对角线外全是 1；(b) 主对角线上有 1；(c) 某一行（也就是对应的列）全是 0。
2. 邻接表：约 |V| + 2|E| = 1000 + 4000 = 5000 个单元；邻接矩阵：10⁶ 个单元。用**邻接表**。
3. 行 a: [0 1 1]，行 b: [0 0 1]，行 c: [1 0 0]。有环 a→c→a，**不是** DAG。
   入度：a=1, b=1, c=2；出度：a=2, b=1, c=1。
4. 结点 = 课程，有向边 X → Y 表示 X 是 Y 的先修课。能修完 ⇔ 图是 **DAG**；
   修课顺序就是一个**拓扑排序**（下一章）。
