## 1. 本课程的伪代码规范

课上和 Levitin 课本用的是同一种风格。只要**清楚、无歧义、不像某种真实编程语言**就行。

### 1.1 基本语法对照表

| 想表达 | 伪代码写法 | 不要写成 |
|---|---|---|
| 赋值 | `x ← 5` | `x = 5;` |
| 相等判断 | `if x = y then` | `if (x == y) {` |
| 不等 | `x ≠ y`（考试可打 `!=`） | |
| 计数循环 | `for i ← 0 to n − 1 do` | `for (int i=0; i<n; i++)` |
| 倒序循环 | `for i ← n downto 1 do` | |
| 条件循环 | `while j ≥ 0 and A[j] > v do` | |
| 函数 | `function Find(A[0..n−1], x)` | `def find(A, x):` |
| 返回 | `return j` | |
| 记录字段 | `p.val`、`p.next`、`T.left` | |
| 空指针 | `null` 或 `nil` | `None` |
| 交换 | `swap(A[i], A[j])` | |
| 向下取整 | `⌊n/2⌋`（考试可打 `floor(n/2)`） | `n // 2` |
| 注释 | `▷ 这里是注释` 或 `// 注释` | |
| 集合 | `S ← ∅`，`S ← S ∪ {v}` | |

缩进表示代码块（不需要 `end if`，但写了也没关系）。

### 1.2 一个标准示例（线性查找，来自第 2、3 讲）

```
function Find(A[0..n−1], x)
    j ← 0
    while j < n do
        if A[j] = x then
            return j
        j ← j + 1
    return −1
```

### 1.3 写伪代码的好习惯（设计题评分点）
1. 写出函数名和参数，说明数组下标从 0 还是 1 开始。
2. 用到的辅助数组要写"初始化"那一步，例如 `for i ← 0 to n−1 do visited[i] ← False`。
3. 调用课上算法时写清名字：`Mergesort(A)`、`HeapSort(H)`、`DFS(G)`、`Dijkstra(G, s)`。
4. 写完后**用一个小例子手动跑一遍**，检查边界（空数组、只有一个元素、找不到）。

## 2. 必备数学

### 2.1 求和公式（分析循环必用）

| 公式 | 结果 | 阶 |
|---|---|---|
| Σ_{i=l}^{u} 1 | u − l + 1（项数 = 上限 − 下限 + 1） | — |
| Σ_{i=1}^{n} i = 1 + 2 + … + n | n(n+1)/2 | Θ(n²) |
| Σ_{i=1}^{n} i² | n(n+1)(2n+1)/6 | Θ(n³) |
| Σ_{i=0}^{n} aⁱ（a ≠ 1） | (aⁿ⁺¹ − 1)/(a − 1) | Θ(aⁿ) |
| Σ_{i=0}^{n} 2ⁱ | 2ⁿ⁺¹ − 1 | Θ(2ⁿ) |
| Σ_{i=1}^{n} log i = log(n!) | — | Θ(n log n) |
| 1 + 1/2 + 1/3 + … + 1/n | ≈ ln n | Θ(log n) |

**最常见的陷阱：项数**。Σ_{i=0}^{n−2} 1 = n − 1，而不是 n − 2。

### 2.2 对数

- log_a(xy) = log_a x + log_a y；log_a(x^c) = c·log_a x
- 换底：log_a n = (log_a b)·(log_b n) ⇒ **所有底数的对数增长率相同**，所以写 Θ(log n) 不写底数
- 2^{log₂ n} = n
- log₂ 1024 = 10，log₂ 10⁶ ≈ 20（二分查找 100 万个数最多 20 次比较）
- n 每次减半，减到 1 需要 ⌊log₂ n⌋ 次

### 2.3 取整
- ⌊x⌋ 向下取整，⌈x⌉ 向上取整
- ⌊n/2⌋ + ⌈n/2⌉ = n（归并排序把数组分成这两半）

### 2.4 常见增长率从慢到快（第 3 讲，必背）

```
1  ≺  log n  ≺  √n (或 n^ε, 0<ε<1)  ≺  n  ≺  n log n  ≺  n²  ≺  n³  ≺  2ⁿ  ≺  n!  ≺  nⁿ
```

记忆小技巧：
- 任何多项式 n^c 最终都比任何 (log n)^k 大。
- 任何指数 cⁿ (c>1) 最终都比任何多项式大。
- n! 比 2ⁿ 大（Stirling：n! ≈ √(2πn)(n/e)ⁿ）。

## 练习

1. 计算 Σ_{i=0}^{n−1} Σ_{j=i+1}^{n−1} 1。
2. 计算 Σ_{i=3}^{n} 1 的项数。
3. 把下列函数按增长率从小到大排：n², 2ⁿ, n log n, √n, log² n, n!, 100。
4. 把下面的 Python 改写成课程风格伪代码：
   ```python
   def count_neg(A):
       c = 0
       for x in A:
           if x < 0: c += 1
       return c
   ```

<details>
<summary>答案</summary>

1. 外层第 i 轮，内层执行 (n−1) − (i+1) + 1 = n − 1 − i 次。
   Σ_{i=0}^{n−1}(n−1−i) = (n−1) + (n−2) + … + 0 = n(n−1)/2。
2. n − 3 + 1 = n − 2 项。
3. 100 ≺ log² n ≺ √n ≺ n log n ≺ n² ≺ 2ⁿ ≺ n!。
   （注意 log² n 指 (log n)²，它仍然比 √n 慢。）
4. ```
   function CountNeg(A[0..n−1])
       c ← 0
       for i ← 0 to n − 1 do
           if A[i] < 0 then
               c ← c + 1
       return c
   ```
